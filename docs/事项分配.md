## 三、详细事项卡片

### T-01 师傅端视觉验收（P0 · 本周）
- **背景**：师傅端 8 页已全量接入真实接口（M7/M10 完成），但无浏览器环境，缺视觉验收证据，交付不完整。
- **责任人**：测试工程师（微信开发者工具导入 `broadband-worker/`）。
- **交付物**：
  1. 8 个页面真机/模拟器截图（首页、工单列表、工单详情、完工确认、排班、路线、评价、个人中心）；
  2. 《师傅端视觉验收报告》一份（对照设计系统 v2.0 主题色 #ea580c、间距、组件一致性）。
- **验收标准**：截图齐全、与设计规范无重大偏差（偏差清单 ≤ 3 项且可后续迭代修复）。
- **依赖**：微信开发者工具 + `broadband-worker/project.config.json` 的 AppID（当前占位 `wxWORKER_APPID_TODO`，提审前需注册注入）。
- **状态**：待办。

### T-02 生产密钥与默认口令治理（P0 · 上线前必做）
- **背景**：`app.jwt.secret` 为默认密钥；admin/admin123 为默认口令，存在生产安全风险。
- **责任人**：后端开发 + PM 评审。
- **交付物**：
  1. `JWT_SECRET` 通过环境变量 / 配置中心覆盖（不落库明文）；
  2. 默认管理员首登强制改密逻辑；
  3. 上线安全检查清单勾选记录。
- **验收标准**：默认密钥不可直接用于生产；首登改密流程实测通过。
- **状态**：待办（阻塞于上线前窗口）。

### T-03 微信支付真集成（P1 · 阻塞）
- **背景**：v1.11 打通交易闭环，但支付为 Mock 桩（`PayService` seam 已预留），缺真实通道。
- **责任人**：后端开发。
- **交付物**：微信支付 v3 接入（下单 / 回调验签 / 退款 / 对账单），替换 `PayService` 桩实现。
- **依赖（阻塞项）**：用户/业务方提供 ① 微信支付商户号 ② APIv3 密钥 ③ 平台证书。
- **验收标准**：真实小额支付→回调→订单状态机→退款全链路跑通（演示环境）。
- **状态**：阻塞（待凭证）。

### T-04 PC 后台扩展深化（P1 · 下一迭代）
- **背景**：G10 缺口——客户 360、套餐营销、SLA 看板三页已存在但可深化。
- **责任人**：前端开发 + 后端开发。
- **交付物**：
  1. 客户 360 视图补充生命周期/触达记录；
  2. 套餐营销看板补充转化漏斗；
  3. SLA 看板补充超时热力与赔付趋势。
- **验收标准**：三页接入实时数据，关键指标可下钻。
- **状态**：待办。

### T-05 配置动态刷新（P2）
- **背景**：G7 已落地多环境 profile + 字典/配置表，但动态刷新未做。
- **责任人**：后端开发。
- **交付物**：`@RefreshScope` / Apollo `ConfigChangeListener` 热刷新关键配置（容量规则、SLA 阈值、参数项）。
- **验收标准**：改 `sys_config` 后无需重启即生效（或提供刷新端点）。
- **状态**：待办。

### T-06 压测长稳（P2）
- **背景**：G9 已用 k6 落地基础压测，可补 JMeter 长稳。
- **责任人**：测试工程师。
- **交付物**：JMeter 长稳脚本（≥ 2h）+ 容量基线报告（QPS / RT / 错误率）。
- **验收标准**：长稳期无内存泄漏、错误率 < 0.1%。
- **状态**：待办。

### T-07 多端 / 国际化（P3 · V2.0）
- **背景**：G11 缺口。
- **责任人**：前端开发。
- **交付物**：i18n 框架 + 多住宅切换；中英文资源占位。
- **验收标准**：关键页面文案可切换；多住宅数据隔离正确。
- **状态**：规划中。

### T-08 v1.14 运营与留存（P3 · 规划草案）
- **背景**：路线图 v1.14 主题。
- **责任人**：产品 + 全栈。
- **交付物**：积分成长体系、优惠活动专区、在线客服/帮助中心。
- **验收标准**：三模块上线且可运营配置。
- **状态**：规划草案。

### T-09 / T-10 M15 上线保障（规划）
- **T-09**：运维搭建 CI/CD 流水线 + 生产 Nginx 反代部署；依赖 T-02 安全治理完成。
- **T-10**：PM 产出文档终版基线并组织复盘会。
- **状态**：规划（上线前执行）。

### T-11 V2.0 智能化与多端（规划中）
- 依赖 T-07（i18n/多住宅）与 T-08（留存能力）奠基。
- **状态**：规划中。
