## 二、版本变更记录

- **v1.1**：Phase 2「数据持久化与真实联调」—— 后端接入 MySQL，REST 接口全部读写真实数据。
- **v1.2**：Phase 3「PC 后台 + 安全体系」—— 新建 `web-admin`，接口 13→45、表 17→25；落地 Spring Security 6 + JWT + RBAC（21 权限码 / 5 角色）。
- **v1.3**：小程序补页（M7）—— 客户端 7→15 页，新建师傅端 8 页；统一请求封装注入 Bearer token。
- **v1.4**：修复小程序真实缺陷（M7 收尾）—— 登录态升级为真实 JWT；修复 4 个契约/逻辑缺陷。
- **v1.5**：M9「双端登录态正式收口」—— C 端强制鉴权 + CUSTOMER 令牌；师傅端 `worker-login` + WORKER 令牌；微信 `code2Session` 双路径。
- **v1.6**：M10「师傅端数据全绑定」—— 新增 `WorkerController`（6 接口）；服务端按 token 隔离；13 项验证全绿。
- **v1.7**：M10 收尾「凭证落地」—— 客户端写入真实 AppID `wxcc344ad7f4f849d4`；师傅端接口口径修正。
- **v1.8**：M11「业务闭环联调」—— 打通下单→支付→派单→装机→SLA 赔付→评价；PayService 支付 seam；端到端 36 项断言全绿。
- **v1.9**：三端 UI 优化（小程序双端）—— 统一设计系统 v2.0 + 客户端骨架页重写 + 师傅端 8 页全量重写。
- **v1.10**：M12 数据分析闭环—— 销售/财务后端 + `biz_order.region`。
- **v1.11**：交易真闭环—— 退款/对账状态机、电子发票占位、评价闭环增强（微信支付真集成除外）。
- **v1.12**：质量与运维工程化—— CI/CD + 压测 + 监控深化 + 配置治理。
- **v1.13（本轮）**：客户端核心自助 + 平台治理—— 故障报修全流程、数据字典、参数配置、运营/财务 PC 页全量接入实时数据。
