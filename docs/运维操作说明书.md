## 3. 本地验证（推荐 · 已实测）

核心算法与接口契约以「纯 Java 引擎 + Demo」形式提供，**无需 Maven 与数据库**即可编译运行，用于快速验证业务逻辑。

```bash
cd backend
rm -rf /tmp/bwall && mkdir -p /tmp/bwall

# 编译所有「纯 Java」类（排除 mapper/、spring/ 与 MyBatis 实体 TrafficRecord）
find src/main/java/com/broadband -name "*.java" \
  | grep -v '/mapper/' | grep -v '/spring/' | grep -v 'TrafficRecord.java' \
  | tr '\n' '\0' | xargs -0 javac -d /tmp/bwall

# 依次运行 3 个模块的 6 个 Demo
java -cp /tmp/bwall com.broadband.community.CommunityDemo
java -cp /tmp/bwall com.broadband.install.DispatchDemo
java -cp /tmp/bwall com.broadband.install.SlaDemo
java -cp /tmp/bwall com.broadband.product.PackageDemo
java -cp /tmp/bwall com.broadband.product.PackageUpgradeDemo
java -cp /tmp/bwall com.broadband.product.TrafficDemo
```

**实测结果**：49 个类编译通过，6 个 Demo 全部运行成功（派单全派完/超容拦截、SLA 赔付、升档补差 70×18=1260、流量阈值等场景均正确）。

## 4. 完整应用运行（需 Maven + 数据库）

> 下列步骤用于启动完整 Spring Boot 服务（含 Controller/Mapper）。需先安装 Maven 并配置数据库。

```bash
# 1) 安装依赖并打包
cd backend
mvn clean package -DskipTests

# 2) 运行（默认端口 8082，见 application.yml）
java -jar target/broadband-dispatch-1.0.0.jar
# 或开发态热运行
mvn spring-boot:run
```

启动后接口示例：
```bash
curl "http://localhost:8082/api/community/check?name=南山科技园"
curl "http://localhost:8082/api/package/detail?id=demo"
curl "http://localhost:8082/api/traffic/usage?customerId=C10086"
curl -X POST "http://localhost:8082/api/package/upgrade" \
  -H 'content-type: application/json' \
  -d '{"targetExtra":40,"addonExtra":30}'
```

## 5. 配置模板（application.yml）

```yaml
server:
  port: 8082

spring:
  application:
    name: broadband-system
  datasource:
    # 按实际选用 MySQL / PostgreSQL / Oracle，驱动见 pom 注释位
    url: jdbc:mysql://127.0.0.1:3306/broadband?useSSL=false&serverTimezone=UTC
    username: ${DB_USER:root}
    password: ${DB_PWD:root}
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  configuration:
    map-underscore-to-camel-case: true
  global-config:
    db-config:
      id-type: assign_id

# Apollo 配置中心（规划）：动态下发容量/SLA/特征开关
# apollo:
#   bootstrap:
#     enabled: true
#     namespaces: application, broadband-rules
```

> 数据源未配置时，Controller 当前以 mock 返回，服务仍可启动用于接口联调。

## 6. 部署建议

- **进程**：以 `java -jar` 运行，建议配合 `nohup` / systemd / 容器。
- **反向代理**：Nginx 转发 `/api/*` 到 `:8082`，统一 HTTPS 与限流。
- **小程序**：`utils/api.js` 中 `globalData.baseUrl` 指向网关地址（如 `https://api.example.com`）；本地联调可填 `http://<本机IP>:8082`。
- **配置管理**：接入 Apollo 后，容量阈值（`CapacityPolicy`）、SLA 规则（`SlaRulePresets`）改为远程配置，支持热刷新。

## 8. 常见故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `javac` 报 `程序包com.baomidou不存在` | 误编译了 mapper/spring 或 MyBatis 实体 | 按第 3 节命令排除 mapper/、spring/、TrafficRecord |
| `command not found: mvn` | Maven 未安装 | 安装 Maven 3.8+ 并配置 `JAVA_HOME` |
| 接口返回空/mock | 未接数据库，Controller 走 mock | 属预期；接库后去除 mock |
| 端口被占用 | 8082 已被占用 | 改 `server.port` 或释放端口 |
| 小程序请求失败 | baseUrl 未配置/跨域 | 配置 `globalData.baseUrl`；后端放开 CORS（规划） |
| 派单全超容 | 单师傅容量上限过低 | 调整 `CapacityPolicy` 或 `worker_capacity` 配置 |

## 9. 数据库初始化（MySQL，参考）

```sql
CREATE DATABASE IF NOT EXISTS broadband DEFAULT CHARSET utf8mb4;

-- 小区覆盖
CREATE TABLE community (
  id VARCHAR(32) PRIMARY KEY,
  name VARCHAR(128),
  street VARCHAR(128),
  lat DOUBLE, lng DOUBLE,
  covered TINYINT(1) DEFAULT 1,
  port_total INT DEFAULT 0,
  port_used INT DEFAULT 0
);

-- 装维人员与容量
CREATE TABLE worker (
  id VARCHAR(32) PRIMARY KEY,
  name VARCHAR(64),
  skill_level INT DEFAULT 1
);
CREATE TABLE worker_capacity (
  id VARCHAR(32) PRIMARY KEY,
  worker_id VARCHAR(32),
  time_slot VARCHAR(16),          -- 2026-09-14#AM
  adjacent_cap INT DEFAULT 4,
  non_adjacent_cap INT DEFAULT 2
);
CREATE TABLE work_order (
  id VARCHAR(32) PRIMARY KEY,
  community_id VARCHAR(32),
  time_slot VARCHAR(16),
  status VARCHAR(16),
  worker_id VARCHAR(32)
);

-- 套餐（主表 + 轮播图 + 动态参数 + 组成）
CREATE TABLE package (
  id VARCHAR(32) PRIMARY KEY, name VARCHAR(128), category VARCHAR(32),
  monthly_fee INT, original_fee INT, status VARCHAR(16),
  deposit INT, device_rent INT, penalty INT, sla_info VARCHAR(255)
);
CREATE TABLE package_image (id VARCHAR(32) PRIMARY KEY, package_id VARCHAR(32), url VARCHAR(255), sort_order INT);
CREATE TABLE package_param (id VARCHAR(32) PRIMARY KEY, package_id VARCHAR(32), group_key VARCHAR(32), name VARCHAR(64), type VARCHAR(16), required TINYINT(1), sort_order INT);
CREATE TABLE package_param_option (id VARCHAR(32) PRIMARY KEY, param_id VARCHAR(32), label VARCHAR(64), value VARCHAR(64), sort_order INT);
CREATE TABLE package_converge (id VARCHAR(32) PRIMARY KEY, package_id VARCHAR(32), item VARCHAR(128), sort_order INT);
CREATE TABLE package_upgrade_order (
  id VARCHAR(32) PRIMARY KEY, customer_id VARCHAR(32), from_pkg VARCHAR(32),
  to_bandwidth VARCHAR(16), addons VARCHAR(128),
  month_diff INT, one_time_diff INT, effect_type VARCHAR(16), status VARCHAR(16), created_at DATETIME
);

-- 装维 SLA 与赔付
CREATE TABLE sla_rule (
  id VARCHAR(32) PRIMARY KEY, order_type VARCHAR(20), sla_name VARCHAR(64),
  eval_type VARCHAR(16), promise_hours INT, grace_minutes INT,
  min_speed_mbps INT, comp_type VARCHAR(24), comp_amount INT,
  max_comp_amount INT, status VARCHAR(16)
);
CREATE TABLE sla_record (id VARCHAR(32) PRIMARY KEY, order_id VARCHAR(32), rule_id VARCHAR(32), eval_type VARCHAR(16), result VARCHAR(16), overtime_minutes INT, comp_amount INT, evaluated_at DATETIME);
CREATE TABLE compensation (id VARCHAR(32) PRIMARY KEY, record_id VARCHAR(32), customer_id VARCHAR(32), comp_type VARCHAR(24), comp_amount INT, status VARCHAR(16), created_at DATETIME);

-- 流量
CREATE TABLE traffic_usage (
  id VARCHAR(32) PRIMARY KEY, customer_id VARCHAR(32), period_month VARCHAR(7),
  mobile_total INT, mobile_used INT, broadband_hours INT,
  broadband_peak VARCHAR(16), daily_trend VARCHAR(64), updated_at DATETIME
);
```

> 详细字段与索引见各模块文档（`SLA.md` / `PKG_COMMUNITY.md` / `PKG_TRAFFIC.md`）。
