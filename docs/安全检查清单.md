## 四、已识别风险与处置建议

| 风险 | 影响 | 建议处置 |
|---|---|---|
| `/api/pay/simulate/**` 生产仍放行 | 任意人可伪造支付成功，造成资金損失 | 上线前用 `@Profile("dev")` 或条件配置关闭；或改为仅 `enabled=false` 的 Mock 模式下可用 |
| 演示登录回退（`VITE_ALLOW_DEMO_LOGIN`） | 后端不可达时前端可无凭证登录 | 生产构建确保该变量为 `false` |
| 默认口令未及时更换 | 默认管理员账号可被直接登录 | 依赖首登强制改密（第 6/8 项）；上线前人工确认 |
| 审计日志无留存策略 | 事后追溯困难 | 定义留存周期（建议 ≥180 天）并限制 `sys_oper_log` 写入权限 |
| 监控告警缺失（R8） | 异常无主动发现 | ✅ 已收口：docs/monitoring/ 已交付 Prometheus 抓取 + 告警规则 + Grafana dashboard + docker-compose；部署时落地 deploy/monitoring/，业务指标告警待后端补 MeterRegistry 埋点 |
