# 宽带业务管理系统 · 数据结构说明书

> 数据库：MySQL 8.4 ｜ 框架：Spring Boot 3 + MyBatis-Plus
> 命名约定：表名/列名 snake_case；Entity 字段 camelCase（MyBatis-Plus 自动映射）。
> 脚本 `schema.sql` 全部为幂等写法（`CREATE TABLE IF NOT EXISTS` + `information_schema` 守卫补列），可安全重复执行。
> 保留字桥接：`package_converge_item.description` → 接口字段 `desc`；`package_param_option.option_value` → 接口字段 `value`。
> 本文档共 **31 张表**，按 7 大域分组；V1.13 新增表与列以「V1.13」标注。

## 附：V1.13 变更摘要

- **work_order 新增列**：`type`（工单类型）、`fault_category`（故障类型，关联字典）、`fault_desc`（故障描述）、`contact_phone`（报修联系电话），支撑故障报修全流程。
- **新增字典表**：`sys_dict_type`、`sys_dict_data`，将原硬编码枚举（故障类型/工单类型/时段）外置为可维护数据。
- **新增参数表**：`sys_config`，承载客服电话、报修 SLA 时长、派单默认容量等系统级可配置参数。
- 上述补列均以 `information_schema` 守卫的 `ALTER TABLE ... ADD COLUMN` 幂等写入，可重复执行不报错。
