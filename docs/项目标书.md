## 一、项目背景与建设需求

随着宽带业务向「线上报装、透明装维、精细运营」转型，运营商亟需一套覆盖**终端客户、装维师傅、运营后台**三端的一体化系统，打通「下单 → 支付 → 智能派单 → 装机 → SLA 评估/赔付 → 评价 → 退款/开票」的业务闭环，并以数据驱动运营决策。

**核心诉求**：
1. 客户侧：自助报装/续费/提速/报修，订单全流程可追溯。
2. 师傅侧：移动接单、容量可视、完工测速与评价闭环。
3. 运营侧：RBAC 精细权限、数据权限行级隔离、销售/财务/客户 360 聚合看板。
4. 工程侧：可监控、可压测、可 CI/CD、可容器化交付。

---

## 三、总体技术方案

- **架构**：后端单体 Spring Boot 3.2.1（JDK 21），前端 Vue 3 + 微信原生小程序双端；Nginx 反代。
- **数据**：MySQL 8.4，28 张表，MyBatis-Plus（Boot3 专用）。
- **安全**：自研 HS256 JWT + Spring Security 6，RBAC 21 权限码 / 5 角色 / 26 菜单三处同源。
- **工程**：GitHub Actions CI/CD + 多阶段 Dockerfile + k6 压测 + Prometheus 监控。
- **原则**：单体优先、模块收敛（模块上限 5）、配置原生（不引 Apollo）、零三方安全依赖。
