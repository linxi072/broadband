**接口清单（13 个：GET 8 / POST 5）**

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/community/check | 小区可安装性校验 |
| POST | /api/community/demand | 未覆盖小区安装需求登记 |
| POST | /api/dispatch/run | 执行派单（聚类 + 容量校验 + 超容拦截） |
| GET | /api/dispatch/capacity | 师傅时段容量看板 |
| POST | /api/sla/evaluate | 单条 SLA 评估 |
| POST | /api/sla/evaluate-batch | 批量 SLA 评估 |
| GET | /api/sla/board | SLA 看板聚合 |
| GET | /api/sla/rules | SLA 规则列表 |
| GET | /api/sla/compensations | 赔付工单列表 |
| GET | /api/package/detail | 融合套餐详情（图/组成/动态参数） |
| GET | /api/package/upgrade-options | 升档选项 + 当前套餐 + 剩余合约月数 |
| POST | /api/package/upgrade | 提交升档（补差预览 + 落升级申请单） |
| GET | /api/traffic/usage | 客户流量用量与预警 |
