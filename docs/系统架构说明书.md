## 1. 系统定位

宽带业务管理系统面向「宽带办理 + 装维运营」业务场景，覆盖三类使用者：

| 角色 | 载体 | 主题色 | 核心职责 | 状态 |
|---|---|---|---|---|
| 客户端（C 端用户） | 微信小程序 | 蓝 `#2563eb` | 选套餐、查覆盖、下单、升档、流量监控、报修 | ✅ 20 页（含登录态） |
| 安装师傅（装维） | 微信小程序（师傅端） | 橙 `#ea580c` | 接单、排班、路线、完工确认、测速 | ✅ 8 页（独立工程，含登录态） |
| 运营/管理（B 端） | PC 后台（web-admin，Vue 3） | 靛 `#4f46e5` | 套餐/小区/工单/权限/性能/SLA 看板管理 | ✅ 22 业务页 |

> 已落地：**后端 4 个业务模块 / 49 个 REST 接口（真实 MySQL）**、**PC 后台 22 业务页**、
> **RBAC 鉴权体系（5 角色 / 21 权限码）**、**客户端小程序 20 页**、**师傅端小程序 8 页（独立工程 `broadband-worker`）**。

**各层职责**
- **终端层**：界面与交互，统一走封装后的请求层（小程序 `utils/api.js`、后台 `src/api/request.js`）。
- **接入层**：生产用 Nginx 终止 HTTPS、托管前端静态产物并把 `/api/*` 反代到后端；开发期由 Vite dev server 代理。
- **业务服务层**：按业务域拆模块，每个模块遵循「纯 Java 引擎可独立验证 + Spring 适配层组装」的同构设计；
  安全拦截在 Servlet Filter 链完成（无状态 JWT），细粒度授权用方法级 `@PreAuthorize`。
- **数据层**：MyBatis-Plus Mapper 承载业务读写；后台聚合类只读查询用 JdbcTemplate 直接 SQL（多表联查更直观）。

## 5. 同构分层设计（关键约定）

每个业务模块采用一致分层，便于维护与替换数据源：

```
com.broadband.{community|install|product}/
├── <Module>Demo.java        # 纯 Java 可独立运行验证（无 Spring 依赖）
├── model/                   # 纯 POJO / VO / 实体（与 DB 表对应，零 ORM 注解）
├── engine/                  # 核心算法（纯 Java，可单测/可独立运行）
├── mapper/                  # MyBatis-Plus Mapper 接口
└── spring/                  # ServiceApi / ServiceImpl / Controller
```

**约定（均已落地并遵守）**
- `engine` 不依赖 Spring，输入/输出为纯对象，可 `javac` + `java` 单独验证。
- `model` **零 ORM 注解**（不加 `@TableName`）：主键在 Service 层用 `Ids.next()` 显式生成，
  保证实体类可被纯 Java 编译；表名依赖配置的驼峰/下划线映射。
- `spring` 层只做「组装 DB 数据 → 调用 engine → 落库/返回」，不含业务判断。
- **保留字桥接**：`package_converge_item.description`（`desc` 是 SQL 保留字）与
  `package_param_option.option_value` 在 Mapper 内用 `@Select` 别名映射回接口字段 `desc` / `value`，从而
  **保住前端 JSON 契约不变、实体保持零注解**。

## 8. 关键设计决策

1. **算法与框架解耦**：派单、SLA、补差、流量四类核心算法均为纯 Java `engine`，可脱离 Spring 独立编译运行与单测。
2. **实体零 ORM 注解**：不引入 `@TableName` / `@TableId`，主键在 Service 显式生成；受限于保留字的列用 Mapper 内 `@Select` 别名桥接。
3. **派单容量策略**：相邻小区（同街道或距离 ≤ 800m）每时段 3–4 单、非相邻 1–2 单；并查集聚类后按容量贪心派单，超出即拦截并给出改派/增派建议。
4. **SLA 规则引擎**：时限类（承诺 = 受理/预约 + 承诺小时 − 宽限）与速率类（测速 ≥ 最低速率）双模型；赔付按 `PER_ORDER` 或 `PER_OVERTIME_HOUR` 计算并封顶。
5. **升档补差公式**：`月差 = 目标带宽加价 + 增值加价`；`一次性补差 = 月差 × 合约剩余月数（30 天/月）`；`新月费 = 当前月费 + 月差`。
6. **流量阈值提醒**：`remaining = total − used`，`warn = remaining ≤ 5`（G），触发加购建议。
7. **鉴权无状态 + 授权实时**：token 只承载会话标识（账号/用户ID/姓名/部门/签发/过期），
   **角色与权限码每请求实时查库**——后台改授权立即生效，无需用户重新登录，也避免"权限固化进 token"的经典难题。
8. **开放层与受保护层分离**：小程序 c 端接口（套餐/小区/流量）默认放行，管理端接口全部要求登录 + 权限码；
   开关 `app.security.protect-client-api` 一处收口，便于小程序登录态就绪后平滑切换。
9. **后台聚合用 JdbcTemplate**：多表联查 + 别名对齐前端字段的只读报表，用直写 SQL 比 ORM 更直观可控；
   注意**联表查询必须给列加表别名**（曾因 `SELECT id` 歧义返回 500）。

## 9. 安全与权限（已落地）

**模型**：RBAC 五表（用户 / 角色 / 菜单 / 用户角色 / 角色菜单）+ 操作日志表。

| 角色码 | 名称 | 菜单数 | 权限码数 | 典型可见范围 |
|---|---|---|---|---|
| `ADMIN` | 超级管理员 | 26 | 21 | 全部模块 |
| `OPERATOR` | 运营专员 | 19 | 15 | 全部业务模块 |
| `FINANCE` | 财务 | 4 | 4 | 看板 / 订单 / 客户 / 财务 |
| `CS` | 客服 | 4 | 4 | 看板 / 订单 / 客户 / 投诉评价 |
| `SALES` | 销售 | — | — | 看板 / 订单 / 客户 / 销售（种子角色） |

**实现要点**
- `SecurityFilterChain`：关闭 csrf / formLogin / httpBasic，`SessionCreationPolicy.STATELESS`，JWT 过滤器前置于 `UsernamePasswordAuthenticationFilter`。
- **自研 JWT**（`JwtUtil`）：HS256，仅用 JDK 的 `Mac` + `Base64`，**零三方依赖**，可独立单测；
  含签发、签名校验（常量时间比较）、过期校验、扁平 JSON 声明解析。
- **密码**：BCrypt（`PasswordEncoder`）；`data.sql` 只插入账号骨架，初始密码由 `RbacInitializer` 幂等写入
  （已有密码不覆盖，用户改过的密码不会被启动流程重置）。
- **审计**：登录成功/失败、越权访问、写操作全部落 `sys_oper_log`。
- **密钥治理**：`app.jwt.secret` 必须通过环境变量在生产覆盖（默认值仅供开发）。
- **回归保障**：`JwtUtilTest` 7 条用例覆盖数字声明解析、篡改签名、篡改载荷、过期、密钥错配、格式非法。

- **按需引入**：组件走 `unplugin-vue-components` 的 `ElementPlusResolver`，命令式 API（`ElMessage` / `ElMessageBox`）

- **菜单驱动而非写死**：登录后 `GET /api/auth/me` 返回 `menus`（树），Sidebar 据此渲染；
  无权限的菜单不下发，天然与后端权限一致。
- **主题**：靛 `#4f46e5` 作为主色，收敛在 `src/styles/index.css` 的 CSS 变量中。

### 10.2 小程序（客户端 `broadband-miniapp` + 师傅端 `broadband-worker`，两独立工程）

- 结构：`app.js/json/wxss` + `pages/*` + `utils/api.js` + `utils/auth.js` + `project.config.json` / `sitemap.json`。
- `utils/api.js`：统一请求封装，`request()` 统一注入本地 `Bearer` token，且**非 2xx 显式 reject**（不再静默吞错）；`login` 调 `POST /api/auth/miniapp-login` 换取真实 JWT。
- 客户端已落 **20 页**（蓝 `#2563eb`）：`index / service / package(detail,list,upgrade) / upgrade / community/query / order(address,confirm,list,detail) / address / traffic / move / self / smart / review / profile / settings / login`。
- 师傅端（独立工程 `broadband-worker`，橙 `#ea580c`）已落 **8 页**：`index / order / order-detail / confirm / capacity / schedule / profile / login`。
- 登录态：`utils/auth.js` 提供 `isLogin/requireLogin`；`profile` 页 `onShow` 登录门禁；`app.setClientLogin/setWorkerLogin` 写 token + 本地存储。
